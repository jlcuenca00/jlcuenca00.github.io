# Jake Cuenca — Personal Portfolio

A personal portfolio website presenting my work as a developer and visual creative. The site uses a split landing page that leads to two distinct experiences: a red technical **Developer** portfolio and a blue image-led **Creator** portfolio.

## Live Site

**GitHub Pages:** https://jlcuenca00.github.io/

## Developer Portfolio

The Developer side contains the academic and professional information required for my personal portfolio project, including:

- Home / introduction
- Profile and short biography
- 4th Year BS Information Technology status
- Technical, creative, and professional skills
- Selected software projects
- Complete education history
- Leadership and media experience
- Certificates and credentials
- Downloadable resume / CV
- Contact information

## Design Direction

The portfolio intentionally avoids using one identical template for every section. The **Developer** experience uses dark interfaces, red signal accents, technical metadata, a project index, system-style motion, and a scanner cursor. The **Creator** experience uses blue accents, larger photography, editorial spacing, and lens-inspired interactions. The landing page connects the two visual identities.

## Responsive & Accessibility Notes

- Keyboard-focus states for interactive controls
- `prefers-reduced-motion` support
- Descriptive image alternative text
