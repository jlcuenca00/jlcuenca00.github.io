# Project Screenshots

Place the actual system screenshots for the Developer portfolio in this folder using these exact filenames:

- `dar-ltcms.png` — actual DAR-LTCMS system screenshot; recommended landscape 1600×900 or larger.
- `periphora.png` — actual Periphora app screenshot; portrait is acceptable and will be contained without cropping.
- `wordspace.png` — actual Wordspace typing website screenshot; recommended landscape 1600×900 or larger.

The portfolio already points to these exact paths and shows designed placeholders when a file is missing. Replacing the placeholders only requires adding the PNG files here; no HTML/CSS edit is needed.

Use screenshots of the working systems themselves rather than mockups, logos, or decorative illustrations so the project presentation satisfies the portfolio requirement.
